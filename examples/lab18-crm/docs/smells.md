| # | Smell    | Baseline example                             | Rationale                                                                                                                                 |
|---|----------|----------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Poor Naming | a,b,c,d,e,data                               | These names do not communicate their business purpose. Readers must rely on comments to understand that `a` is an ID and `e` is a status. |
| 2 | Raw Collection Type | `List data = new ArrayList();`               | The list has no generic type, so Java cannot guarantee that it contains only `Customer` objects.                                          |
| 3 |   Long method       | `doStuff(...)`does almost everything.        | Combining many operations makes the method difficult to understand, test, and modify safely.                                              |
| 4 |Stringly typed status | `e.equals("ACTIVE")`, `e.equals("PROSPECT")` | Status is represented as text even though `CustomerStatus` already exists.                                                                |
| 5 | Incorrect equality         | `x.getCustomerId() == id`                    | `==` compares object references rather than String contents                                                                               |
| 6 |    Null as control flow      | `return null` for invalid input, duplicate ID |                                                                                                                                           |
| 7 |    Side-effect logging      | `System.out.println("bad")`                   | The messages are vague, and  difficult to test                                                                                            |
| 8 |    Magic behavior      |     `b.contains("UPDATE")` triggers an update                                          |   A customer’s name unexpectedly controls application behavior                                                                                                                                        |
